# OCR-B Tesseract traineddata

This directory contains Tesseract traineddata packaged into the OCR sidecar image.

`ocrb_int.traineddata` is the fast/integer OCR-B model from `Shreeshrii/tessdata_ocrb`, a community Tesseract 4 traineddata set for MRZ text using OCR-B fonts.

Source:

```text
https://github.com/Shreeshrii/tessdata_ocrb/blob/master/ocrb_int.traineddata
```
